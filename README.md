# Sam's Science Lab Game

A single-file study game for 7th grade science (Is It Alive, Organization of Life, Microscopes).
Modes: flashcards, quiz, matching, speed round, biotic or abiotic, put in order, give me 5, missed items, study guide.
Progress saves in the browser (localStorage). No external dependencies.

Lessons 11 and 12 (West Africa) have their own game at `west-africa/`: https://brookhouser.github.io/sam-science-game/west-africa/
